# 🐌 Verificador Caracolístico

> **Um software extremamente sério para um problema que não existe.**

O Verificador Caracolístico é um programa feito com tecnologia de ponta, orçamento de R$ 0,00 e uma quantidade preocupante de tempo livre.

Sua função é verificar caracóis. Não pergunte quais caracóis. Não sabemos.

## 🤡 O que isso faz?

- Verifica caracóis imaginários.
- Tem uma chance de entrar em pânico durante a verificação.
- Exibe mensagens dramáticas sobre o estado do computador.
- Finge deletar o sistema e os programas.
- Revela a verdade no final: **o caracol foi verificado!**

## 💻 Isso faz alguma coisa com meu computador?

**Não. As mensagens de exclusão são apenas encenação.**

O programa foi pensado como uma brincadeira visual. Ele não precisa apagar arquivos, desinstalar programas, formatar discos nem modificar o Windows para fazer sua piada.

O único dano conhecido é a perda temporária de produtividade e a possível confusão de quem estiver olhando para a tela.

## 🛠️ Qualidade do código

Vamos ser honestos: **o código é muito malfeito**.

- Arquitetura: discutível.
- Utilidade prática: inexistente.
- Interface: terminal com letras coloridas.
- Design: vermelho e verde, porque aparentemente isso é tecnologia.
- Segurança contra caracóis: não comprovada.
- Testes com caracóis reais: nenhum.
- Chance de ganhar um prêmio de engenharia: um caracol talvez tenha mais chances.

Este projeto não é um exemplo de boas práticas de programação. Ele existe porque alguém teve uma ideia idiota e resolveu programá-la em vez de ir dormir.

## 🚀 Como executar

Se você tiver o executável `Caracol.exe`, abra-o no Windows.

Se tiver o código-fonte `caracol.ps1`, poderá executá-lo pelo PowerShell. As configurações de segurança do Windows podem impedir a execução de scripts; não altere políticas de segurança globais só para rodar esta brincadeira.

## ⚠️ Aviso

Este projeto é uma brincadeira, sem finalidade profissional, comercial ou científica.

Não é um antivírus, não verifica caracóis de verdade e não oferece proteção ao computador. As mensagens dramáticas são falsas.

Use apenas versões cujo código você possa inspecionar. Um arquivo executável baixado de terceiros pode ter sido alterado e não é automaticamente seguro só por ter o mesmo nome.
