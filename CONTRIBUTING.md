# Como contribuir

Obrigado por se interessar pelo **Verifique os Caracóis**!

Este projeto é uma brincadeira e deve continuar simples, transparente e inofensivo.

## Diretrizes

- Mantenha todas as mensagens claramente fictícias e humorísticas.
- Não adicione funções que apaguem, alterem, criptografem ou enviem arquivos.
- Não colete informações pessoais nem se comunique com servidores.
- Não altere configurações do sistema, inicialização ou ferramentas de segurança.
- Não use persistência, ocultação, evasão de antivírus ou execução disfarçada.
- Atualize o README sempre que o comportamento real mudar.
- Prefira publicar o código-fonte junto das versões executáveis, para que outras pessoas possam inspecionar o projeto.

## Relatando problemas

Abra uma issue descrevendo o comportamento observado e os passos para reproduzi-lo. Não inclua senhas, dados pessoais ou arquivos privados.
